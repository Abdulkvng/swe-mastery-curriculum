# Interview Study Plans

## 7-Day Crash Plan

### Day 1 — C++ ownership and containers
Read Phase 00 + Phase 01. Do C++ quiz. Implement/modify vector/reserve and object-layout experiments.

### Day 2 — CPU architecture
Read Phase 02 + Phase 03. Run cache and branch labs. Explain pipeline and cache hierarchy aloud.

### Day 3 — Concurrency
Read Phase 04. Build SPSC queue from a blank file after studying the provided version. Explain acquire/release proof.

### Day 4 — Performance methodology
Read Phase 05 + 06. Run benchmarks. Write one mock `perf stat` diagnosis. Practice p99/tail-latency cases.

### Day 5 — Trading
Read Phase 07 + 08 + 11. Implement order book from scratch. Do microstructure quiz.

### Day 6 — Quant + DSA
Read Phase 09 + 12. Do quant quiz. Solve 5 timed C++ problems and discuss cache/allocation tradeoffs after each.

### Day 7 — Full mocks
Run Mock A and Mock B under strict timing. Review only missed concepts. End with 100-question rapid-fire drill.
